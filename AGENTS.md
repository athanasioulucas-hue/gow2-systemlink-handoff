# Agent Rules

1. Inspect the repository and Git status before editing.
2. Understand the task and acceptance criteria before changing files.
3. Make the smallest coherent change that solves the task.
4. Do not rewrite whole files when a targeted patch will work.
5. Do not perform unrelated cleanup, renaming, or refactoring.
6. Test the narrowest relevant behavior first.
7. Do not repeat the same failed attempt more than twice without reassessing.
8. Never hide errors or claim success without evidence.
9. Preserve existing user changes and avoid destructive Git actions.
10. At task completion, update LATEST.md with:
    - what changed;
    - files changed;
    - validation performed;
    - observed result;
    - blockers;
    - exact next action.
